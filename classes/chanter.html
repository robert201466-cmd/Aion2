      How to use this
      
      
    
      
    
        
      
      1. Add skills — click any card in the library, or load a starter combo.
        2. 
      
      2. Order them — drag a row by its handle, or use the ↑ / ↓ buttons.
        3. 
      
      3. Tune each step — slot (hotbar number), wait (ms cap for the ability to fire) and target. Leave a field empty to use the defaults above.
        4. 
      
      4. Exact IDs — the ID on a card is the base skill. A real character uses a specialization child ID, so either tick Use hotbar slots (recommended), or paste your exact ID from -hotbar into the step's id box.
        5. 
      
      5. Trigger key — every key from Speeder's virtual key code table, grouped, including mouse buttons (left, right, middle, side buttons, scroll) and the left/right modifier variants. Use 160/161 for Shift, not 16. Letters, digits and symbols work, but the key is swallowed while the macro runs.
        6. 
      
      6. Icons — most skills ship with their game icon in icons/; the rest show a generated badge.
        7. 
    
      
    
      
      Timings are estimates taken from the client's attack timers; cooldown warnings assume every step finishes back to back.
      A macro that passes Speeder's verifier is not proof it works in game.
